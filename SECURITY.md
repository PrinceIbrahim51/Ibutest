# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through
GitHub's "Report a vulnerability" button (Security tab → Advisories) for this repository.

Include the affected version/commit, reproduction steps and impact. We aim to acknowledge
reports within 3 business days and to ship fixes for high/critical issues within 14 days.

## Supported versions

Only the latest release (the default branch) receives security fixes.

See [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md) for the security controls, the audit
